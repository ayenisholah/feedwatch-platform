# Dashboards

`feeds.json` is generated by [`../build-dashboard.py`](../build-dashboard.py). Edit the script, run `python3 grafana/build-dashboard.py`, and commit both files; CI fails if they differ. The datasource UID is `feedwatch-influx`, and the dashboard UID is `feedwatch-feeds`.

Panels (FR-FW-8):

- feeds checked, feeds not ok, open incidents and last cycle duration;
- the 25 feeds closest to their heartbeat (age as % of heartbeat);
- feeds not ok now;
- distance from the reference price for ETH, BTC and USDC on each chain;
- RPC latency and failed requests by provider;
- poll cycle duration;
- incidents over the last 30 days.

A `chain` variable filters every panel.
