# Requirements

**Updated:** 2026-11-18 · **Related:** [Specification](../SPEC.md) · [Roadmap](ROADMAP.md) · [Test strategy](TEST_STRATEGY.md)

Every requirement has an ID, a testable acceptance check, the repo that delivers it, how it's verified and a status. A requirement is `done` only when its check has passed and a test named `[ID] …` exists.

**ID prefixes:** `FR-FW` functional · `NFR` non-functional · `GR` guardrail.
